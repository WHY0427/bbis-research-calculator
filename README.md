# BBIS Research Calculator

This repository contains the browser-based implementation of the blood-based inflammatory score (BBIS) developed using UK Biobank data.

The calculator accepts either routine blood measurements or pre-calculated NLR and PLR values and returns the standardized BBIS and the corresponding UK Biobank reference quartile. All calculations are performed locally in the browser; entered values are not transmitted or stored.

## Intended use

This tool is provided for research use only. It is not a diagnostic instrument, does not estimate an individual's absolute dementia risk, and should not be used to guide clinical decisions.
